# プラハ城さんぽ

チェコ・プラハ、ヴルタヴァ川を見下ろす丘の上の「城の町」プラハ城を、スマホで歩いて巡る3D散策。
世界さんぽシリーズ（ヴェルサイユ宮殿さんぽ・ノイシュヴァンシュタイン城さんぽ）と同じ操作系（three.js r128・単一HTML）。

- 城：フラッチャニ広場（大司教宮殿・シュヴァルツェンベルク宮殿・マリアの柱）、巨人の門と衛兵、第一の中庭、マティアス門、第二の中庭（コールの噴水・聖十字架礼拝堂）、第三の中庭（オベリスク・聖イジーの騎馬像）、旧王宮、聖イジー広場、イジー通り、黒い塔と東の門
- 聖ヴィート大聖堂：西の正面と2本の尖塔・バラ窓、身廊（網目の丸天井・ステンドグラス・ムハの窓・オルガン）、黄金の門（「最後の審判」のモザイク）、聖ヴァーツラフ礼拝堂（半貴石の壁）、内陣（王の霊廟・主祭壇・聖ネポムツキーの銀の墓）、飛び梁
- 大塔：入口の戸口で「上る」→ 287段のらせん階段 → 高さ55mの展望の回廊（登城の印）
- 旧王宮：ヴラジスラフ・ホール（曲線のリブの天井）、ボヘミア官房（1618年の窓外投擲事件の窓）
- 聖イジー教会（ロマネスクの中・赤い正面・アダムとイヴの塔）、黄金の小路（色とりどりの小さな家・カフカの22番の家）、白い塔、ダリボルカ塔、ロブコヴィッツ宮殿
- 庭：南庭園（雄牛の階段・プレチニクの鉢・ベルヴュー東屋・窓外投擲のオベリスク）、火薬橋と鹿の堀、王宮庭園（球戯場・王妃アンナの夏の離宮・歌う噴水）
- 町：東の展望台、古城の階段、マラー・ストラナ（赤い屋根の家並み・聖ミクラーシュ教会）、カレル橋（聖人像・聖ネポムツキー像・両端の橋塔）、旧市街の塔、ペトシーンの丘と展望塔、飢えの壁
- とき：1370年ごろ カレル4世（大聖堂の内陣は建設中・古いロマネスクの聖堂・カレル橋も工事中）／1600年ごろ ルドルフ2世（大聖堂は内陣と大塔だけで西は仮の壁・黄金の小路に射手の家）／現在
- 時刻：朝・昼・夕・夜（現在は投光、昔は窓の灯り）、季節：夏・秋・冬（雪）、天気：晴れ・川霧
- 見どころ札集め（全52か所・歩いて訪れたときだけ。localStorage `prague_fuda`）、登城の印（`prague_seal`）、写真モード、道案内（光の矢印。大塔の階段もまたぐ）、合成音（風・川・歌う噴水のしずく・大聖堂のオルガンの和音・ホールのリュート風の音・町の鐘・1370年の石工の音）

建物や町は写真や資料をもとにした簡略な再現で、距離や建物の大きさは歩きやすく縮めています。方角はおおむね実際どおり（北が王宮庭園、南東にカレル橋）。1370年・1600年の姿には推定を含みます。
